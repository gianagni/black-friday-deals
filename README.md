Bargain Beacon is a real Black Friday deal finder: 36 deals checked on 27 Nov 2026, each with its product, store, sale price, usual price, discount, store link, check time and source, plus an honest verdict on whether it is really a deal (7 new lows, 27 strong prices, 2 routine sales). Search, filters by category, store and discount, and sorting by discount, saving or price all work in the browser, on desktop and on a phone. The site is plain static files with no build step and no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
